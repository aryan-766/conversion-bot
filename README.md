## 🌟 Key Pillars & Features

1. **🚀 MagicChat.ai Inspired SaaS Landing Page**
   - High-converting modern SaaS dark theme with glassmorphic cards and glowing ambient neon accents.
   - Live Interactive Hero Chat Simulator embedded directly on the homepage.
   - Dynamic **ROI & Revenue Lift Calculator** with traffic, AOV, and CVR sliders.
   - Interactive Tiered Pricing matrix with Monthly/Annual savings toggle.
   - Wall of Love customer testimonials & FAQ accordion.

2. **🔐 Complete Authentication UI**
   - 1-Click **Continue with Google** & **Continue with GitHub** social authentication.
   - Email / Password Login, Registration, "Remember Me", and Password Reset magic links.

3. **⚡ AI Model Playground & Prompt Studio**
   - Multi-Model Router: **GPT-4o**, **Claude 3.5 Sonnet**, **Gemini 1.5 Pro**, **DeepSeek V3**.
   - Hyperparameter controls: Temperature, Max Completion Tokens, Custom System Prompt Directives.
   - Real-time **RAG Vector Chunk Inspector** showing cosine similarity % and source documents.
   - Live interaction latency (ms) & token cost estimator ($/query).

4. **📊 Merchant Conversion Attribution & Intelligence Dashboard**
   - **Executive Overview**: Total visitors, high intent count, proactive interventions, leads, and AI-assisted revenue.
   - **Visitor Intelligence Stream**: Real-time multi-signal Intent Scoring (0–100 pts: *Cold*, *Interested*, *High Intent*, *Hot 🔥*).
   - **Trigger & Intervention Studio**: Multi-condition rules for *Product Hesitation*, *Comparison Paralysis*, *Cart Abandonment*, and *Exit Intent*.
   - **AI Specialist Studio**: Objective presets (*Sales Closer*, *Product Advisor*, *Lead Qualifier*, *Support Agent*).
   - **Knowledge Base & Continuous Sync**: 1-click web crawler, sitemap parser, and autonomous **Knowledge Gap Engine** that flags missing answers from live conversations for 1-click approval.
   - **Campaigns & Offers**: Intent-gated coupon codes (`SAVE10`, `FIRSTFIT`) strictly communicated by schema guardrails.
   - **Leads CRM**: Captures and qualifies high-intent customer inquiries, callback requests, and bulk orders.
   - **A/B Testing Lab**: Scientifically isolates experimental lift (Control vs AI Agent) with statistical significance.

5. **🛍️ Interactive D2C Storefront Simulation ("AuraFit Luxe") + Live Sales Widget**
   - Realistic footwear & athletic apparel e-commerce store with PDP, size selectors, customer reviews, and cart drawer.
   - Real-time telemetry: triggers dwell hesitation, size guide opens, and cursor exit intent.
   - Embeddable lightweight widget (<48KB footprint) with structured product recommendation cards and instant checkout.

## 🚀 Getting Started

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/aryan-766/conversion-bot.git
cd conversion-bot
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open `http://localhost:3000` to view the SaaS Landing Page, Playground Studio, Merchant Dashboard, and Live D2C Storefront.

### 3. Build for Production
```bash
npm run build
```
